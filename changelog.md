# Changelog

## 0.1.1 - 2026-11-18

- Add shared EditorConfig, Prettier, and VS Code settings.
- Add `format:fix` and keep formatting commands consistent with Prettier's
  default ignore files so validation passes.

- Add `Nullable<T>`, `Optional<T>`, and `Dictionary<T>` as explicit type exports.
- Provide a checked-in declaration entry point for GitHub installations pinned

- Add compiler tests, formatting checks, documentation, and GitHub Actions CI.
